# izlog_beta

A temporary beta of [izlog](https://same-same-ia.github.io/izlog/) with a reverb (odjek) and a
delay (jeka), for listening tests on phones. Synthesized voice only. This page will be removed
once the effects are built into izlog itself.

Built from the IMM-izlog recipe `experiments/preview/make_efekti_proba.py` (proba 6).
